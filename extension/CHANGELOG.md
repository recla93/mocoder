# Changelog

All notable changes to mocoder. Versions follow [semantic versioning](https://semver.org): 0.x are pre-releases,
1.0.0 will be the first stable release.

## 0.2.0 — 2026-11-15

First version tested end to end: a 12-task Java path generated by a free model, completed from the panel.

### Added
- **Three roads for the AI**, chosen once: free without an account (prompt for a web chatbot + import), free API
  (Gemini), pay-as-you-go API (DeepSeek); plus Claude, Ollama and any OpenAI-compatible provider (e.g. OpenRouter).
- **Backup API key**: mocoder asks before switching provider when the first one is down; it never switches on its own.
- **Milestone review** button in the panel.
- Backlog verification tells a **missing tool or dependency** (or a JDK older than the project needs) apart from a
  wrong check, with what to install.
- Offline tips name the failing tests and lines for `assertTrue` without a message.
- Example path `broken`, to try verification and offline diagnostics.

### Changed
- Interface, prompts and docs in English; generated paths, tutor and reviews follow the language of your idea.
- The Planner follows the technologies named in the idea and keeps its feasibility assessment after a repair.
- The tutor never rewrites the corrected version of your own line in `guided` mode.

### Fixed
- *Configure AI* skipped the provider menu and silently chose Ollama.
- `mvn exec:java` checks without a compile step (fixed automatically on import).
- The reference solution's backups could end up in the project's git history.
- The panel said "saved to git" when the commit had failed (e.g. git without name and email).
- A stuck provider froze the tutor; a failed question was lost; Ctrl+Enter dropped a question while the tutor was thinking.

## 0.1.0 — 2026-11-07

First installable package: backlog with red → green checks, scaled hints, one commit per task, optional AI tutor.
